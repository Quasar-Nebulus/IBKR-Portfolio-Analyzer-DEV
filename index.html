ℹ️ Comment utiliser ?

  1. Exportez vos données depuis Interactive Brokers en format CSV
  2. Sélectionnez les fichiers CSV via le bouton ci-dessus
  3. Cliquez sur "Importer et traiter"
  4. Vos données seront sauvegardées localement dans votre navigateur
  5. Explorez les données via l'onglet "Explorer"
